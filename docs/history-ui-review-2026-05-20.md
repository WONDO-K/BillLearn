# BillLearn 내역 화면 UI/UX 비교

작성일: 2026-05-20

이 문서는 현재 내역 화면을 초기 시안의 내역 화면과 비교하고, 다음 구현 작업의 범위를 정하기 위해 작성한다.

## 기준 자료

- 디자인 기준: `docs/assets/brand/core-ui-screens.png`의 내역 화면
- 현재 캡처: `docs/screenshots/billlearn-history-seeded.png`
- 관련 코드: `app/lib/src/features/history/history_screen.dart`

## 시안의 내역 화면 구조

시안의 내역 화면은 다음 정보 구조를 가진다.

1. 상단 타이틀: `내역`
2. 필터 행: `잔여 기간`, `전체 카테고리`, 검색 아이콘
3. 월 요약 카드: 전체 지출 금액과 거래 건수
4. 일자별 그룹: `5월 20일 (월)`, `5월 19일 (일)` 같은 날짜 헤더
5. 거래 카드 묶음: 같은 날짜 거래를 하나의 흰 카드 안에 compact list로 표시
6. 거래 행: 가맹점 아이콘, 가맹점명, 시간, 카테고리 chip, 금액

## 현재 구현 상태

현재 내역 화면은 다음 구조다.

1. 상단 앱바: `BillLearn`
2. 요약 카드: `내역`, 설명 문구, 확정 지출 합계, 확정/검토/제외 count
3. 섹션 헤더: `정리된 지출 흐름`
4. 거래 카드: 각 거래를 독립 card로 표시
5. 상태 표현: 확인 필요/제외 거래는 chip 또는 취소선으로 구분

## 맞춰진 부분

- 확정/검토/제외 거래를 한 화면에서 구분한다.
- 확인 필요 거래는 일반 확정 지출과 별도 상태로 보인다.
- 거래를 누르면 상세 화면으로 이동한다.
- 확정 지출 합계를 상단에서 확인할 수 있다.

## 부족한 부분

- 시안의 필터 행이 없다.
- 검색 아이콘이 없다.
- 월 요약 카드가 시안보다 크고, 정보 밀도가 낮다.
- 거래가 일자별로 그룹화되어 있지 않다.
- 같은 날짜 거래가 하나의 카드 안에 묶이지 않고 거래마다 독립 카드로 표시된다.
- 홈에서 만든 merchant fallback 아이콘과 category chip이 내역에는 아직 적용되지 않았다.
- 시안의 `전체 지출 1,248,500원 / 235건` 같은 compact summary 구조와 다르다.
- 앱바 타이틀은 현재 shell 기준으로는 `내역`으로 바뀌었지만, 기존 캡처는 오래된 상태라 최신 캡처 갱신이 필요하다.

## 다음 구현 범위

다음 작업에서는 실제 필터/검색 기능은 만들지 않고, UI 틀만 만든다.

1. 내역 화면 상단에 필터 row 추가
2. 검색 아이콘 버튼 추가
3. 요약 카드를 compact monthly summary card로 변경
4. 거래를 날짜별로 그룹화
5. 날짜별 거래를 흰 rounded card 안의 list로 묶기
6. 홈과 동일한 merchant fallback 아이콘과 category chip 적용

## 구현하지 않을 것

- 실제 기간 필터 동작
- 실제 카테고리 필터 동작
- 검색 화면 또는 검색 결과
- 서버 동기화
- 분석 탭

## 권장 순서

1. 홈의 `_MerchantVisual`, `_MerchantMark`, `_CategoryChip` 로직을 내역에서도 쓸 수 있게 공통화한다.
2. 내역 화면 테스트를 `월 요약`, `날짜 그룹`, `거래 card list`, `확인 필요 상태` 기준으로 갱신한다.
3. 내역 화면 UI를 시안 구조로 재배치한다.
4. 에뮬레이터에서 샘플 데이터 캡처를 갱신한다.

## 결론

내역 화면은 기능적으로는 동작하지만, 시안의 정보 구조와는 아직 거리가 있다. 다음 개발 작업은 기능 추가보다 레이아웃 재구성이 우선이다. 특히 홈과 내역의 거래 행 표현을 통일해야 앱 전체가 같은 제품처럼 보인다.
