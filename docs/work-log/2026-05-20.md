## 완료한 작업

### 홈 한도 문구 정리

- 홈 히어로 카드의 `예산` 문구를 `월 지출 한도`로 변경했다.
- 수입/입금 기능이 없는 현재 MVP에서는 잔액 기반 예산이 아니라 사용자가 정할 소비 한도 개념으로 제한하는 것이 맞다고 정리했다.
- 홈 화면 테스트의 기대 문구를 `월 지출 한도 1,800,000원`으로 갱신했다.
- UI 스크린샷 문서와 UI/UX 회고 문서에서도 `예산` 표현을 `월 지출 한도` 기준으로 정리했다.
- 에뮬레이터에서 홈 화면을 다시 캡처해 카드 내 문구가 자연스럽게 들어가는지 확인했다.

## 검증 기록

- `dart format lib test`: 완료
- `flutter test test\features\home\home_screen_test.dart`: 3개 통과
- `flutter build apk --debug`: 성공
- `adb install -r`: 에뮬레이터 설치 성공
- `adb screencap`: 홈 `월 지출 한도` 문구 캡처 완료

## 현재 평가

- 홈의 지출 요약 카드는 시안 구조를 유지하면서도 현재 MVP 기능 범위와 더 맞는 문구가 됐다.
- 예산 관리 기능을 만들기 전까지는 `월 지출 한도`가 가장 안전한 표현이다.
