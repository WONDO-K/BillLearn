# 2026-05-20 작업 로그

## 작업 원칙

- 전날 UI/UX 회고 문서의 우선순위를 기준으로 진행한다.
- 기능 범위를 바꾸는 요청이 아니라면 기존 예정 작업을 유지한다.
- 커밋 메시지는 `[Feat]`, `[Fix]`, `[Docs]` 머릿말과 한국어 설명을 사용한다.

## 완료한 작업

### 홈 한도 문구 정리

- 홈 히어로 카드의 `예산` 문구를 `월 지출 한도`로 변경했다.
- 수입/입금 기능이 없는 현재 MVP에서는 잔액 기반 예산이 아니라 사용자가 정할 소비 한도 개념으로 제한하는 것이 맞다고 정리했다.
- 홈 화면 테스트의 기대 문구를 `월 지출 한도 1,800,000원`으로 갱신했다.
- UI 스크린샷 문서와 UI/UX 회고 문서에서도 `예산` 표현을 `월 지출 한도` 기준으로 정리했다.
- 에뮬레이터에서 홈 화면을 다시 캡처해 카드 내 문구가 자연스럽게 들어가는지 확인했다.

### 내역 화면 시안 비교

- `docs/history-ui-review-2026-05-20.md`를 추가했다.
- 시안의 내역 화면 구조와 현재 구현 구조를 비교했다.
- 다음 구현 범위를 필터 row, compact summary, 일자 그룹, 거래 카드 묶음, merchant icon/chip 적용으로 좁혔다.
- 실제 필터/검색 동작은 MVP 현재 단계에서는 제외하기로 정리했다.

### 내역 화면 시안 구조 재정렬

- 홈에 있던 merchant fallback icon/category chip 로직을 `shared` 위젯으로 공통화했다.
- 내역 화면 상단에 `잔여 기간`, `전체 카테고리`, 검색 아이콘 row를 추가했다.
- 전체 지출 합계와 거래 건수를 compact summary card로 재구성했다.
- 거래를 날짜별로 그룹화하고, 같은 날짜 거래를 하나의 흰 rounded card 안에 표시하도록 바꿨다.
- 확인 필요/제외 거래의 상태 chip과 금액 표현을 새 거래 행 구조에 맞춰 유지했다.

## 현재 평가

- 홈의 지출 요약 카드는 시안 구조를 유지하면서도 현재 MVP 기능 범위와 더 맞는 문구가 됐다.
- 예산 관리 기능을 만들기 전까지는 `월 지출 한도`가 가장 안전한 표현이다.
