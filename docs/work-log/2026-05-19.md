# 2026-05-19 작업 로그

## 작업 원칙

- UI 작업은 에뮬레이터에서 실제 화면을 확인하고 스크린샷을 남긴다.
- 기존 예정 작업은 사용자가 명시적으로 바꾸지 않는 한 유지한다.
- 커밋 메시지는 `[Feat]`, `[Fix]`, `[Docs]` 같은 머릿말과 한국어 설명을 사용한다.

## 완료한 작업

### 설정/진단 화면 1차 UI polish

- 설정 화면 상단을 홈/내역/상세와 같은 light purple 히어로 카드로 재구성했다.
- 알림 접근 권한과 SMS 권한 카드를 rounded white card 스타일로 정리했다.
- 권한 상태 chip을 `켜짐`, `꺼짐`, `확인 실패` 상태 pill로 변경했다.
- 개발자 도구 카드와 샘플 거래 생성 버튼을 같은 카드 톤으로 정리했다.
- 수집 진단 카드에서 최근 수집 건수, 마지막 raw body, 파싱 결과, 판별 결과, reason code가 더 읽기 좋게 보이도록 스타일을 정리했다.

### 탭 화면 하단 여백 보강

- 홈/내역/설정 탭의 `ListView` 하단 padding을 통일했다.
- bottom navigation 위로 마지막 카드가 충분히 올라오도록 하단 여백을 120px로 조정했다.
- 설정 화면을 하단까지 스크롤한 상태에서 수집 진단 카드가 가리지 않는지 에뮬레이터로 확인했다.

### 브랜드 앱 아이콘 반영

- 사용자가 제공한 `04_app_icon_purple_reference.png`를 앱 아이콘 원본 asset으로 추가했다.
- Android launcher icon용 `mipmap-mdpi`부터 `mipmap-xxxhdpi`까지 PNG 리소스를 재생성했다.
- 마스코트 SVG 원본을 `assets/brand/brand_mascot.svg`로 추가해 이후 앱 내부 일러스트에 활용할 수 있게 했다.
- `pubspec.yaml`에 브랜드 asset 경로를 등록했다.

### UI 스크린샷 문서 정리

- 에뮬레이터에서 확보한 홈/내역/상세/설정 화면을 `docs/ui-screenshots.md`에 정리했다.
- 샘플 데이터가 있는 상태와 초기 빈 상태 캡처를 구분했다.
- 각 화면별 확인 포인트와 현재 UI gap을 문서화했다.
- README 문서 목록에서 UI 스크린샷 문서로 이동할 수 있게 링크를 추가했다.

### 상세 화면 판별 근거 하단 캡처

- 샘플 거래 중 `동백전 충전` 상세 화면을 하단까지 스크롤해 판별 근거 영역을 캡처했다.
- 파싱 후보, 판별 chip, 신뢰도, reason code가 실제 화면에서 노출되는지 확인했다.
- `docs/ui-screenshots.md`에 상세 판별 근거 캡처와 확인 포인트를 추가했다.
- 기존 UI gap 중 `판별 근거 하단 전체 캡처 필요` 항목을 완료 처리했다.

### 홈 빈 상태 마스코트 적용

- 앱 내부에서 SVG asset을 렌더링할 수 있도록 `flutter_svg` 의존성을 추가했다.
- 홈의 빈 상태 카드에 재사용 가능한 마스코트 뱃지 위젯을 적용했다.
- SVG 원본 캔버스 여백 때문에 마스코트가 작게 보이는 문제를 `Transform.scale`과 clipping으로 보정했다.
- 홈 화면 테스트에 `BillLearn mascot` semantics assertion을 추가해 빈 상태 마스코트 노출을 검증했다.
- 앱 데이터 초기화 후 에뮬레이터에서 빈 홈 상태를 캡처하고 `docs/ui-screenshots.md`에 반영했다.

### 홈 화면 시안 구조 1차 재정렬

- 상단 앱바를 `BillLearn` 텍스트에서 `홈` 타이틀과 알림 아이콘 구조로 변경했다.
- 홈 히어로 카드를 시안의 빨간 영역처럼 `이번 달 총 지출`, 예산, 진행률, 전월 대비 상태, 검토 알림 수 중심으로 재구성했다.
- 히어로 카드 오른쪽에 브랜드 마스코트를 배치하고, SVG 원본 배경을 투명화해 카드 위에서 사각 배경이 보이지 않게 했다.
- `AI가 헷갈린 거래` 섹션명을 `빌런의 인사이트`로 바꾸고, 현재 MVP 범위에서는 확인 필요 거래를 보여주는 방식으로 유지했다.
- 최근 거래 영역을 시안의 노란 영역처럼 흰 rounded card 내부의 compact list로 재구성했다.
- 예산 관리 기능은 아직 없으므로 월 예산은 UI 구조 검증용 임시 기준값으로 주석 처리했다.

### 홈 최근 거래 가맹점 아이콘 fallback 개선

- 정식 가맹점 로고 asset이 없는 상태에서 `merchantName` 기반 아이콘 mapping을 추가했다.
- `배달의민족`, `스타벅스`, `네이버`, `쿠팡`, `동백전`에 브랜드 색상/라벨 fallback을 적용했다.
- mapping이 없는 가맹점은 기존처럼 카테고리 색상과 초성 기반 fallback을 사용한다.
- 이후 정식 로고 asset을 받으면 `_MerchantVisual.from`만 교체하면 되도록 홈 아이콘 로직을 한 곳에 모았다.

### UI/UX 1차 회고 문서 작성

- `docs/ui-ux-review-2026-05-19.md`를 추가했다.
- 시안 대비 현재 맞춰진 부분과 부족한 부분을 홈/내역/상세/설정 단위로 정리했다.
- 예산 영역은 당장 수입/입금 기능이 아닌 `월 지출 한도` 개념으로 제한하는 것이 적절하다고 기록했다.
- 다음 UI 우선순위를 홈 문구 정리, 내역 화면 시안 비교, 내역 화면 재정렬 순서로 재판단했다.

## 현재 평가

- 홈/내역/상세/설정의 1차 UI tone이 모두 같은 방향으로 맞춰졌다.
- 설정 화면은 이전 기본 Card 느낌에서 벗어나 권한과 진단 영역의 위계가 더 분명해졌다.
- 하단 스크롤 캡처 기준으로 `수집 진단` 카드가 bottom navigation에 가리지 않고 확인된다.
- Android 앱 아이콘이 기본 Flutter 아이콘에서 BillLearn 브랜드 아이콘으로 교체됐다.
- 앱 아이콘은 SVG 대신 PNG density 리소스로 반영해 Android launcher에서 깨질 위험을 줄였다.
- UI 스크린샷 문서가 생겨 현재 화면 상태와 다음 UI 개선 포인트를 빠르게 확인할 수 있다.
- 상세 화면의 판별 근거 하단 캡처까지 확보되어 현재 주요 UI 흐름의 시각 자료가 더 완성됐다.
- 홈 빈 상태에 브랜드 마스코트가 들어가 첫 실행 화면의 빈 느낌이 줄고 BillLearn 정체성이 더 잘 보인다.
- 홈 화면은 시안의 핵심 구조인 지출 요약 카드와 최근 거래 카드 틀에 더 가까워졌다.
- 홈 최근 거래 아이콘은 단순 초성에서 merchant-specific fallback으로 바뀌어 시각 식별성이 좋아졌다.
- UI/UX 회고 문서가 생겨 다음 polish 우선순위를 코드 변경 없이 판단할 수 있게 됐다.

## 다음 후보 작업

- 홈의 `예산` 문구를 `월 지출 한도` 또는 `이번 달 목표 한도`로 바꾼다.
- 내역 화면을 시안 기준으로 비교하고 필터/검색/일자 그룹/거래 카드 밀도를 재정렬한다.
- 정식 가맹점 로고 asset을 받을 경우 현재 fallback mapping을 실제 이미지 asset으로 교체한다.
- 실제 Android 기기 준비 시 알림 접근 권한, SMS 권한, 백그라운드 수신을 검증한다.
