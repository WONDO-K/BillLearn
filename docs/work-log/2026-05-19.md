# 2026-05-19 작업 로그

## 작업 원칙

- UI 작업은 에뮬레이터에서 실제 화면을 확인하고 스크린샷을 남긴다.
- 기존 예정 작업은 사용자가 명시적으로 바꾸지 않는 한 유지한다.
- 커밋 메시지는 `[Feat]`, `[Fix]`, `[Docs]` 같은 머릿말과 한국어 설명을 사용한다.

## 완료한 작업

### 설정/진단 화면 1차 UI polish

- 설정 화면 상단을 홈/내역/상세와 같은 light purple 히어로 카드로 재구성했다.
- 알림 접근 권한과 SMS 권한 카드를 rounded white card 스타일로 정리했다.
- 권한 상태 chip을 `켜짐`, `꺼짐`, `확인 실패` 상태 pill로 변경했다.
- 개발자 도구 카드와 샘플 거래 생성 버튼을 같은 카드 톤으로 정리했다.
- 수집 진단 카드에서 최근 수집 건수, 마지막 raw body, 파싱 결과, 판별 결과, reason code가 더 읽기 좋게 보이도록 스타일을 정리했다.

## 현재 평가

- 홈/내역/상세/설정의 1차 UI tone이 모두 같은 방향으로 맞춰졌다.
- 설정 화면은 이전 기본 Card 느낌에서 벗어나 권한과 진단 영역의 위계가 더 분명해졌다.
- 첫 화면 캡처 기준으로 `수집 진단` 카드 하단은 bottom navigation 영역에 일부 걸려 보인다. 기능 문제는 아니지만, 후속으로 진단 카드 하단까지 스크롤 캡처하거나 공통 shell 하단 여백을 점검하는 것이 좋다.
