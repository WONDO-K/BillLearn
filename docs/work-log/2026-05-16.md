## 완료한 작업

### 프로젝트/환경

- 작업 위치를 `E:\workspace\BillLearn` 기준으로 정리했다.
- Flutter/Android SDK/Gradle 캐시는 프로젝트 로컬 `.tools` 경로를 사용한다.
- `feature/billlearn-mvp` 브랜치를 GitHub 원격과 계속 동기화했다.

### 앱 기본 구조

- Flutter 앱 스캐폴드와 기본 라우팅을 구성했다.
- 홈, 내역, 상세, 설정 화면의 기본 구조를 만들었다.
- 하단 탭 네비게이션을 구성했다.
- BillLearn 브랜드 컬러 기반 기본 Material theme을 적용했다.

### Android 수집 기반

- Android `NotificationListenerService`를 추가했다.
- SMS `BroadcastReceiver`를 추가했다.
- Flutter `MethodChannel`, `EventChannel` 기반 Android bridge를 추가했다.
- 알림 접근 권한 설정 이동, SMS 권한 확인/요청 bridge를 추가했다.
- 앱 시작 시 Android raw event stream을 구독하고 처리 파이프라인으로 연결했다.

### 도메인 파이프라인

- `RawNotification`, `TransactionCandidate`, `ClassificationResult`, `ExpenseTransaction` 모델을 추가했다.
- `PaymentTextParser`를 추가해 결제 알림/문자에서 금액, 가맹점, 결제수단 힌트를 추출한다.
- `ExpenseClassifier`를 추가해 실지출/이체성/충전성 문구를 분류한다.
- `ProcessRawNotification` 유스케이스로 raw event 저장, 파싱, 분류, 실제 지출 저장 흐름을 연결했다.

### 로컬 저장소

- `drift + SQLite` 기반 `AppDatabase`와 `LocalExpenseRepository`를 추가했다.
- raw notification과 expense transaction을 로컬 DB에 저장한다.
- repository 계약에 snapshot 조회, 단건 조회, 업데이트 기능을 추가했다.
- 홈, 내역, 상세 화면이 repository 데이터를 읽도록 연결했다.

### 중복/충전 정책

- 일반 결제는 같은 가맹점/같은 금액/짧은 시간이어도 자동 중복 제외하지 않도록 보정했다.
- 같은 `sourceHash`를 가진 raw event는 확정 중복으로 보고 재처리하지 않는다.
- 동백전/지역화폐/페이머니/잔액 충전 같은 stored-value top-up은 실지출에서 제외한다.
- `전기차충전소`처럼 실제 소비에 `충전` 단어가 들어간 경우는 지출로 유지한다.
- 동백전 예시 정책을 반영했다.

```text
카카오뱅크 출금 5,000원
동백전 충전 5,000원
편의점 결제 3,400원

실제 지출: 편의점 결제 3,400원만 저장
```

### 화면 기능

- 홈 화면에서 확정 지출 합계와 최근 지출을 표시한다.
- 확인 필요 거래는 홈에서 별도 섹션으로 표시한다.
- 내역 화면에서 저장된 거래를 최근순으로 표시한다.
- 상세 화면에서 가맹점명, 금액, 결제 시간, 상태, 확인 방식, 동기화 상태, 후보 ID를 표시한다.
- 상세 화면에서 `맞아요`/`아니요` 피드백을 저장한다.
- `아니요`로 제외된 거래는 내역에서 `제외됨` 라벨과 취소선 금액으로 표시한다.
