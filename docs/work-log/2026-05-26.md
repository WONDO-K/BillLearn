- 설정 화면 개발자 도구에서 `대기 중 원천 이벤트 0건` 표시를 확인했다.
- `docs/screenshots/billlearn-settings-pending-queue.png` 캡처를 추가했다.

## 검증 기록

- `flutter build apk --debug`: 성공
- `adb install -r`: 성공
- `adb screencap`: 설정 화면 pending queue 진단 캡처 완료

## 현재 평가

- 실제 기기가 없어 native receiver/service 실행 여부는 아직 검증하지 못했다.
- 다만 에뮬레이터 기준으로 설정 화면의 pending queue 진단 UI는 정상 노출된다.
