- 사용자가 추가한 Figma 무료 에셋은 새 브랜치에서 이어서 검토하도록 분리했다.

### Figma 무료 에셋 인벤토리 작성

- `docs/assets/figma-free-assets` 하위 SVG 5개와 출처 파일을 확인했다.
- `docs/figma-free-assets-inventory.md`를 추가해 참고용/보류/앱 번들 제외 기준을 정리했다.
- 대용량 SVG는 앱에 직접 등록하지 않고 디자인 참고 자료로 유지하는 방향으로 결정했다.

### 홈 화면 UI 1차 업그레이드

- 홈 상단 히어로 카드의 보라 그라디언트, 글로우, 마스코트 배치, 그림자 깊이감을 강화했다.
- 기존 `빌런의 인사이트` 영역을 AI 고도화 전 범위에 맞춰 `검토가 필요한 알림` 패널로 정리했다.
- 최근 거래 카드는 시안처럼 독립된 흰색 카드로 보이도록 라운드와 그림자를 보강했다.
- 에뮬레이터에서 홈 화면을 캡처해 `docs/screenshots/billlearn-home-ui-polish.png`로 저장했다.

### 홈 화면 큰 글자 대응 보정

- 히어로 카드 하단의 `전월 대비 집계 준비 중` 문구가 말줄임 처리되지 않도록 짧은 카피로 조정했다.
- 검토 거래 카드의 보조 문구를 줄여 큰 글자 환경에서도 한 줄에 안정적으로 보이게 했다.
- 보정 후 캡처를 `docs/screenshots/billlearn-home-ui-polish-font.png`로 저장했다.

### 내역 화면 UI polish

- 내역 요약 카드와 날짜별 거래 묶음 카드의 라운드/그림자 깊이를 홈 화면과 맞췄다.
- `확인 필요` 거래 보조 문구를 짧게 조정해 큰 글자 환경에서 잘림 가능성을 낮췄다.
- `DecoratedBox`로 바꾸며 사라진 `InkWell`의 `Material` 조상 문제를 테스트로 확인하고 `Material` 기반 카드로 수정했다.
- 내역 화면 캡처를 `docs/screenshots/billlearn-history-ui-polish.png`로 저장했다.

### 상세 화면 UI polish

- 상세 히어로 카드에 홈/내역과 같은 연한 보라 그라디언트와 그림자 깊이를 적용했다.
- 거래 정보, 피드백, 판별 근거 카드의 라운드와 그림자를 홈/내역 카드와 맞췄다.
- 긴 가맹점명이 히어로 카드에서 레이아웃을 깨지 않도록 한 줄 말줄임 처리했다.
- 상세 화면 캡처를 `docs/screenshots/billlearn-detail-ui-polish.png`로 저장했다.

### 설정 화면 pending queue 진단 캡처 갱신

- 최신 debug APK를 빌드하고 에뮬레이터에 설치했다.
- 설정 화면 개발자 도구에서 `대기 중 원천 이벤트 0건` 표시를 확인했다.
- `docs/screenshots/billlearn-settings-pending-queue.png` 캡처를 추가했다.
- `docs/ui-screenshots.md`에 Settings Pending Queue Diagnostics 섹션을 추가했다.
